- バリの一般観光(観光地・ホテル)は旅行会社系(HIS・阪急交通社・トラベルスタンダード・バリ王)と個人ブログで飽和している。
- 在住者メディア(じゃかるた新聞・Lifenesia)の観光記事は、ニュース寄りか単発の総まとめ。
- 狙い目は「手続き・更新日明記」系。競合の更新日が古いか不明なもの:
  - 観光税。一次情報は在インドネシア日本大使館 https://www.id.emb-japan.go.jp/itpr_ja/oshirase24_02.html
  - e-VOA、All Indonesia 到着カード
  - 長期滞在ビザ比較。例: UMA UMA のビザ記事は2025-03更新で本文が「2023年1月現在」
  - E33G(デジタルノマドビザ)
  - 旅行者向けの病院・保険キャッシュレス手順
- eSIM 比較は乱立しているので避ける(切り口を変える場合のみ)。
- 未調査: 空港送迎・両替詐欺・治安・ゴールデンビザ・学校の競合状況。

## 4. 韓国語向け

- **ニュース分野は空白ではない。** 韓国語のインドネシアニュース媒体が日次で更新している。
  - 한인포스트 https://haninpost.com/
  - 자카르타경제신문 https://www.pagi.co.id/
  - 인니투데이 https://inni-today.com/
  - 데일리 인도네시아(実態未確認)
- **生活・移住ガイド分野は空白の可能性あり(確信度: 低〜中)。** 観光は Trip.com・Klook・KKday の韓国語コンテンツが既にある。Naver のブログ・カフェの中身は未調査。
- **集客面の難しさ:** 韓国の検索シェアは集計元で大きく割れる。StatCounter(2026-03)は Google 46.8% / Naver 44.0%、国内集計(2026-05)は Naver 81.3%。外部の新規サイトが Naver で上位に出るのは難しいと推測(一次データなし)。
- 調査エージェントの推奨: 全面展開はしない。Naver の実態調査 → 韓国語ガイド5〜10本の試験公開 → Search Console で反応確認、の順に小さく検証する。
