# 月次の収益・運用コスト・PV 記録

`revenue-log.csv` に月次で 1 行ずつ記入する。集計は `npm run revenue`。

## 記入手順(翌月初に前月分を記入)

| 列 | 内容 | 取得元 |
|---|---|---|
| `month` | 対象月(`YYYY-MM`) | - |
| `pageviews` | 月間の表示回数(整数) | GA4 の「表示回数」(レポート > エンゲージメント > ページとスクリーン) |
| `adsense_jpy` | AdSense の当月推定収益(円・整数) | AdSense 管理画面のレポート(支払い確定額ではなく当月の収益。円換算後) |
| `affiliate_jpy` | アフィリエイト収益(円・整数) | 各 ASP / 提携先の管理画面(Wise など。承認済み・未承認の扱いは notes に書く) |
| `other_revenue_jpy` | その他の収益(円・整数) | 上記以外(直接取引・寄付など) |
| `cost_jpy` | 当月の運用コスト合計(円・整数) | ドメイン、Gemini API、Google Places API、その他(ホスティング等)の請求・利用明細を合算 |
| `notes` | 補足(任意) | 未承認分の扱い、為替、特記事項など。カンマを含める場合は `"` で囲む |

- 数値は空欄なら「未記入」。0 の場合は 0 と書く(空欄と 0 は区別される)。
- 収益 3 列とコストのいずれかが空欄の月は未記入扱いになる。

## ゴール判定

- 月利益 = `adsense_jpy` + `affiliate_jpy` + `other_revenue_jpy` − `cost_jpy`
- ゴール: **月利益 1 万円以上を 6 か月連続で達成**
- `npm run revenue` は月ごとの利益と、直近の記入済み月から遡った「月利益 1 万円以上の連続月数」を表示する。
  未記入の月・1 万円未満の月で連続が途切れる。
